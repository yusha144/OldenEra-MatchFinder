# Проверка Match Finder в игре

## 1. Подтверждённые результаты

Пользователь подтвердил звук после Alt+Tab в Arena на версиях 0.1.1 и 0.1.2. Журнал 0.1.2 подтверждал событие и успешный звуковой вызов. Версия 0.1.3 сохраняет этот способ воспроизведения и удаляет возврат окна.

Classic, Solo и Arena используют общий обработчик в проверенной сборке. Автономные проверки выполняются для трёх названий режимов. Игровая проверка 0.1.3 и реальный поиск в Classic и Solo не подтверждены.

## 2. Подготовка

Проверьте загрузку версии по журналу, включите `PlaySound`, устройство вывода и системные звуки Windows. Отключите фоновый звук игры. Изменяйте файл настроек при закрытой игре и перезапускайте её.

## 3. Проверка игроком

Для каждого режима поиска проверьте:

- [ ] Alt+Tab до нахождения матча: один сигнал.
- [ ] Сворачивание и Win+D: один сигнал.
- [ ] Переключение на другое окно без сворачивания: один сигнал.
- [ ] Активное окно игры: дополнительного сигнала нет.
- [ ] `PlaySound = false`: сигнала нет.
- [ ] Фоновый звук игры не влияет на сигнал мода.
- [ ] Новый матч после естественной отмены предыдущего: один новый сигнал.

Для последнего случая используйте естественно возникшую отмену. Запишите версию, режим поиска, способ переключения, число сигналов и соответствующие строки журнала. Эта проверка не запускается сборщиком.

# Match Finder

Один звуковой сигнал, когда в Heroes of Might and Magic: Olden Era найден сетевой матч, а игра свёрнута или находится в фоне. Поддерживается уход через Alt+Tab и переключение на другое окно. Если игра уже на переднем плане, дополнительного сигнала нет.

Автор: yusha144. Текущая версия: 0.1.3.

Проект закрытый и готовится к будущей публикации на сайте модов. Публичного выпуска пока нет. Исходники хранятся в отдельном [репозитории GitHub](https://github.com/yusha144/OldenEra-MatchFinder). Условия распространения авторского кода пока не выбраны.

## Возможности

- Общий обработчик поиска для Classic, Solo и Arena.
- Встроенный короткий сигнал независимо от фонового звука игры и её звукового микшера.
- Одна настройка `PlaySound` для включения и отключения сигнала.
- Защита от повторного уведомления об одном матче и от запуска просроченного сигнала.

Мод не возвращает окно на передний план. Игрок самостоятельно переключается в игру и принимает матч. Повторов, выбора собственного звука и автоматического принятия нет. Громкость системных звуков и устройства Windows влияет на слышимость.

Требования: Windows x64, Steam-сборка 25672315 игры, BepInEx Unity.IL2CPP 6.0.0-be.788. При несовпадении проверяемых файлов игры мод отключается. В прежних версиях пользователь подтвердил звук в Arena после Alt+Tab; проверка 0.1.3 и реального поиска в Classic и Solo остаётся в [списке ручных проверок](Docs/testing.md).

## Разработка

В `source/` находятся плагин BepInEx, обработка события и звук; в `tests/` находятся автономные проверки. `tools/generate_sound.py` создаёт исходный WAV, встроенный в DLL. Системные вызовы окна используются только для определения его состояния.

Для разработки нужны .NET SDK 8 или новее, среда .NET 8 для проверок и библиотеки своей игры с установленным BepInEx. Плагин собирается для .NET 6. Укажите реальную папку игры вместо примера:

```powershell
dotnet build .\source\MatchFinder.csproj -c Release '-p:GameRoot=C:\Games\OldenEra'
dotnet run --project .\tests\MatchFinder.Tests.csproj -c Release
```

Для архива из сохранённого коммита используйте `Build-Release.ps1`. В Git не включаются сборки, журналы, настройки игрока и библиотеки игры. В архив входит только DLL этого мода, инструкция и сведения о сборке. Автоматическая сборка на GitHub не настроена.

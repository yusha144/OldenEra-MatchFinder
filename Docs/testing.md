# Проверка Match Finder перед публикацией

## 1. Текущий статус

Звук после Alt+Tab подтверждён пользователем в Arena на версиях 0.1.1 и 0.1.2. Журнал 0.1.2 подтверждал получение события и успешный звуковой вызов. Версия 0.1.3 удаляет возврат окна, сохраняя этот способ воспроизведения.

Общий обработчик Classic, Solo и Arena подтверждён анализом установленной сборки. Автономные проверки логики выполняются для всех трёх названий режимов. Реальное нахождение матча в Classic и Solo пока не подтверждено. Версия 0.1.3 требует проверки в игре самим пользователем.

## 2. Подготовка

Проверьте загрузку 0.1.3 по журналу, включите `PlaySound`, устройство вывода и системные звуки Windows. Отключите фоновый звук самой игры. Меняйте файл настроек при закрытой игре и перезапускайте её.

## 3. Сценарии

Для каждого режима поиска, Classic, Solo и Arena, проверьте:

- [ ] Alt+Tab до нахождения матча: один сигнал, автоматического возврата окна нет.
- [ ] Сворачивание и Win+D: тот же результат.
- [ ] Переключение на другое окно без сворачивания игры: один сигнал.
- [ ] Игра остаётся активной: сигнала Match Finder нет.
- [ ] `PlaySound = false`: сигнала нет и в фоне, и при сворачивании.
- [ ] Включение и отключение фонового звука игры не влияет на сигнал при `PlaySound = true`.
- [ ] Новый найденный матч после естественной отмены предыдущего уведомляет заново; повторов в одном принятии нет.

Не требуется намеренно отменять чужие матчи ради проверки. Последний случай можно отметить, когда он возникнет сам. По возможности повторите проверку в используемых оконном и полноэкранном режимах.

## 4. Перед будущей публикацией

- [ ] Подтвердить загрузку и слышимость 0.1.3 в игре.
- [ ] Заполнить результаты трёх режимов поиска и поддерживаемых режимов отображения.
- [ ] Проверить установку, обновление с прежней версии, сохранение `PlaySound` и удаление отдельно от других модов.
- [ ] Определить сайт модов, условия распространения и окончательное описание выпуска.
- [ ] Собрать архив из окончательного коммита, проверить содержимое и SHA256.

Запишите версию, режим поиска, способ ухода из игры, настройку `PlaySound`, состояние фонового звука, число сигналов и соответствующие строки Match Finder из журнала.

# Лицензия и сторонние компоненты

Код Match Finder, установщик, документация и собственный звуковой файл распространяются по [MIT](../LICENSE), Copyright (c) 2026 yusha144. Звук синтезирован генератором из исходников проекта. Плашка в README создана генератором изображений как иллюстрация звукового уведомления.

Мод использует BepInEx, Harmony и Il2CppInterop. Их двоичные файлы, библиотеки Unity и игровые библиотеки не входят в репозиторий и установочный ZIP. При отсутствии нужных файлов установщик скачивает закреплённые зависимости с серверов BepInEx:

- [BepInEx 6.0.0-be.788](https://builds.bepinex.dev/projects/bepinex_be): [исходники 5b766a3](https://github.com/BepInEx/BepInEx/tree/5b766a3), [лицензия](https://github.com/BepInEx/BepInEx/blob/5b766a3/LICENSE).
- [Базовые библиотеки Unity 6000.0.66](https://unity.bepinex.dev/libraries/6000.0.66.zip).

Адреса и SHA-256 зависимостей зафиксированы в установщике. Сторонние компоненты сохраняют условия своих правообладателей. Match Finder является неофициальным модом для Heroes of Might and Magic: Olden Era.

# Установка и сопровождение Match Finder

## 1. Требования и состав архива

Нужны Windows x64, Steam-сборка 25672315 игры и BepInEx Unity.IL2CPP 6.0.0-be.788. Архив содержит `BepInEx/plugins/MatchFinder/OldenEra.MatchFinder.dll`, `ПРОЧИТАЙ.md` и `release-manifest.json` со сведениями о сборке. Загрузчик, игровые библиотеки и настройки игрока в архив не входят.

Проект пока закрытый, публичного скачивания нет. Локальный проверяемый архив собирается по [инструкции сборки](publishing.md). Архив GitHub Source code содержит исходники и не предназначен для установки в игру.

## 2. Установка и запуск

1. Закройте игру. Если BepInEx ещё не установлен, установите указанную версию загрузчика и один раз запустите и закройте игру, чтобы появились библиотеки `BepInEx/interop`.
2. Проверьте архив: `Get-FileHash -Algorithm SHA256 -LiteralPath '<путь к ZIP>'`. Сумма должна совпадать с соседним файлом `.zip.sha256`.
3. Скопируйте содержимое папки `BepInEx` из архива в корень игры. DLL должна оказаться в `BepInEx/plugins/MatchFinder/OldenEra.MatchFinder.dll`.
4. Запустите игру и найдите в `BepInEx/LogOutput.log` сообщение `Match Finder 0.1.3 загружен`.

Параметры по умолчанию подходят для первого запуска. Инструкция, которая также входит в архив: [ПРОЧИТАЙ.md](../ПРОЧИТАЙ.md).

## 3. Настройка

После первого запуска закройте игру и откройте `BepInEx/config/local.oldenera.matchfinder.cfg`. В секции `Notifications` укажите нужное значение. Пример содержит все настройки текущей версии:

```ini
[Notifications]
PlaySound = true
```

`false` отключает звуковое уведомление. Сохраните файл и заново запустите игру. Отдельного управления громкостью в моде нет: используется громкость системных звуков Windows.

## 4. Проверка работы

Отключите фоновый звук игры, начните поиск и переключитесь через Alt+Tab. При появлении принятия матча должен прозвучать один сигнал. Окно остаётся в том состоянии, в котором его оставил игрок. Вернитесь и примите матч самостоятельно.

В журнале появятся `Найден матч` и `Звуковой вызов Windows выполнен`, если системный вызов завершился успешно. Если игра была активна, ожидается `Уведомление пропущено: игра уже была на переднем плане`. Слышимость подтверждает игрок, а не запись журнала. Полный [список проверок](testing.md) включает Classic, Solo и Arena.

## 5. Обновление, откат и удаление

Обновляйте только при закрытой игре. Сохраните прежнюю DLL и файл настроек вне `BepInEx/plugins`, затем замените DLL новой. Не оставляйте резервную DLL рядом с активными плагинами.

При переходе с 0.1.0-0.1.2 удалите строку `RestoreWindow` и пояснение к ней из секции `Notifications`. Сохраните значение `PlaySound`. Если старую строку оставить, 0.1.3 её игнорирует, но BepInEx может сохранять её в файле как неизвестный параметр.

Для отката закройте игру и верните сохранённые DLL и настройки. Старые версии снова будут иметь прежнее поведение, включая попытку возврата окна, если она включена. Совместимость с обновившейся игрой этим не гарантируется.

Для удаления закройте игру и удалите `BepInEx/plugins/MatchFinder`. Файл настроек можно удалить отдельно. Другие моды и BepInEx оставьте на месте.

## 6. Типовые проблемы

| Наблюдение | Проверка и действие |
| --- | --- |
| Нет сообщения о загрузке | Проверьте путь DLL, журнал BepInEx и отсутствие второй копии мода |
| Мод сообщает о неподдерживаемой сборке | Сохраните журнал; нужна проверка новой игры разработчиком |
| Матч записан, звука нет | Проверьте `PlaySound`, состояние окна в момент события, громкость системных звуков и выбранное устройство |
| Windows не воспроизвела сигнал | Сохраните журнал с режимом и обстоятельствами; автоматического повтора не будет |
| Сигнал есть, окно остаётся в фоне | Это поведение 0.1.3; вернитесь в игру вручную |

Для разбора нужны строки Match Finder, режим поиска, способ ухода из игры и состояние фонового звука. Перед передачей полного журнала проверьте, нет ли в сообщениях других компонентов личных данных.

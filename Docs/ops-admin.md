# Установка и удаление Match Finder

## 1. Требования

Windows x64 и установленная Heroes of Might and Magic: Olden Era, Steam build 26428102.

Для первой установки нужен интернет. Установщик скачивает BepInEx Unity.IL2CPP 6.0.0-be.788 и базовые библиотеки Unity 6000.0.66 с серверов BepInEx и проверяет их SHA-256. Совпадающие установленные зависимости повторно не скачиваются.

## 2. Установка

1. Скачайте [OldenEra-MatchFinder-0.1.6.zip](https://github.com/yusha144/OldenEra-MatchFinder/releases/download/v0.1.6/OldenEra-MatchFinder-0.1.6.zip).
2. Распакуйте ZIP целиком в отдельную папку вне каталога игры.
3. Закройте игру и запустите `Install.bat` из корня распакованного архива.
4. Сверьте путь, который показывает установщик. Если он выводит список копий игры, введите номер нужной копии. Если установщик просит путь, откройте папку установленной игры через библиотеку Steam и укажите полный путь к папке с `HeroesOldenEra.exe`.
5. При запросе подтверждения введите `Д` и нажмите Enter. Дождитесь сообщения об успешном завершении.
6. Запустите игру через Steam.

Прямая ссылка в первом шаге ведёт к готовому установщику. На странице выпуска его также можно найти по полному имени ZIP из первого шага.

Для проверки целостности установочного архива сравните SHA-256 с соседним файлом `.zip.sha256`:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '<путь к архиву>'
```

DLL находится в `BepInEx/plugins/MatchFinder/OldenEra.MatchFinder.dll`. Предыдущие файлы сохраняются в `BepInEx/MatchFinder-backups/<дата-идентификатор>`. Старые дубликаты DLL внутри plugins сохраняются в копии и убираются. Настройки и другие моды сохраняются.

При отличающемся загрузчике или отключённом `doorstop_config.ini` установщик останавливается с сообщением. При ошибке записи заменённые файлы восстанавливаются из резервной копии. Первый запуск с BepInEx занимает дополнительное время на создание библиотек.

## 3. Настройка звука

После первого запуска закройте игру и откройте `BepInEx/config/local.oldenera.matchfinder.cfg`. В секции `Notifications` укажите значение:

```ini
[Notifications]
PlaySound = true
```

`true` включает сигнал, `false` отключает. Сохраните файл и запустите игру. Слышимость зависит от системных звуков Windows и выбранного устройства вывода. Подробности находятся в [справочнике](general.md).

## 4. Проверка работы

В `BepInEx/LogOutput.log` успешная загрузка отмечена строкой `Match Finder 0.1.6 загружен`.

Начните поиск сетевого матча и переключитесь на другое окно. При нахождении матча звучит один сигнал. Переключитесь обратно в игру и примите матч. Если окно игры активно в момент нахождения матча, дополнительный сигнал не звучит.

Записи `Найден матч` и `Звуковой вызов Windows выполнен` подтверждают обработку события и успешный системный вызов. Слышимость проверяется по самому сигналу.

## 5. Обновление и откат

Распакуйте новый установочный архив отдельно, закройте игру и запустите его `Install.bat`. Удалять прежнюю версию перед обновлением не нужно. Существующий `PlaySound`, общие клавиши и соседние моды сохраняются. Если файлы этой сборки уже установлены, появляется сообщение Ничего менять не нужно.

Установщик использует сборку из своего архива. Устаревшая настройка `RestoreWindow` из версий 0.1.0-0.1.2 в 0.1.6 не читается. Её можно удалить вручную, сохранив `PlaySound`.

Для отката при закрытой игре верните прежнюю DLL из указанной установщиком резервной копии в `BepInEx/plugins/MatchFinder`. При необходимости восстановите `local.oldenera.matchfinder.cfg`. Файл `backup.json` перечисляет сохранённые файлы. Резервные DLL хранятся вне plugins. Откат мода не меняет версию игры.

## 6. Удаление

Закройте игру и запустите `Uninstall.bat` из папки распакованного установщика. Проверьте путь к игре. При запросе подтверждения введите `Д` и нажмите Enter.

Удаление убирает копии `OldenEra.MatchFinder.dll` внутри plugins. Настройки, резервные копии, BepInEx и другие моды сохраняются. Интернет для удаления не нужен. Для сброса настроек удалите только `BepInEx/config/local.oldenera.matchfinder.cfg`.

Без установочного архива удалите DLL Match Finder и её дубликаты вручную при закрытой игре.

## 7. Если возникла ошибка

| Сообщение или симптом | Действие |
|---|---|
| Это архив исходников MatchFinder / Это исходники установщика | Скачайте установочный ZIP из раздела 2 и распакуйте целиком |
| Версия игры не подходит | Сверьте Steam build с требованиями |
| Другой или изменённый загрузчик | Укажите версию BepInEx в обращении |
| Загрузка не удалась | Проверьте доступ к серверам BepInEx и повторите установку |
| Отказано в доступе | Закройте игру и проверьте право записи в папку |
| Нет сигнала | Проверьте загрузку мода, PlaySound, устройство вывода и системные звуки. Игра должна находиться в фоне в момент нахождения матча |
| Windows не воспроизвела сигнал | Сохраните относящийся к событию фрагмент журнала и укажите состояние звукового устройства |

Проверка совместимости без установки из корня распакованного архива:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\_files\Install.ps1 -GamePath '<папка игры>' -VerifyOnly -NonInteractive
```

В этом режиме нет скачивания и изменения файлов игры.
